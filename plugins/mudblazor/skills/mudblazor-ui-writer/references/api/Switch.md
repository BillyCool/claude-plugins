# Switch components — API (generated from source)

## MudSwitch<T> : MudBooleanInput<T>

Toggles between two values with the tap of a button, visually distinct from checkboxes. Use switches (not radio buttons) if the items in a list can be independently controlled.

| Parameter | Type | Default | Description |
|---|---|---|---|
| `UncheckedColor` | `Color` | `Color.Default` | The color of this switch when in an unchecked state. Defaults to `Default`. |
| `AriaLabel` | `string?` | `null` | The Aria Label to be assigned to the switch. Defaults to `null`. Used to improve accessibility for screen readers. Adds an `aria-labelledby` to the `input` element. |
| `ThumbIcon` | `string?` | `null` | The icon to display for the switch thumb. Defaults to `null`. |
| `ThumbIconColor` | `Color` | `Color.Default` | The color of the thumb icon. Defaults to `Default`. Only applies when `ThumbIcon` is set. |
