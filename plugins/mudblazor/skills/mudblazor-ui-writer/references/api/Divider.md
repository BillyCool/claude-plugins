# Divider components — API (generated from source)

## MudDivider : MudComponentBase

A thin line that groups content in lists and layouts. Only use dividers if items can't be grouped with open space. Use dividers to group things, not separate individual items.

| Parameter | Type | Default | Description |
|---|---|---|---|
| `Absolute` | `bool` | `false` | Uses an absolute position for this divider. Defaults to `false`. |
| `FlexItem` | `bool` | `false` | For vertical dividers, uses the correct height within a flex container. Defaults to `false`. |
| `Light` | `bool` | `false` | Uses a lighter color. Defaults to `false`. |
| `Vertical` | `bool` | `false` | Displays the divider vertically. Defaults to `false`. |
| `DividerType` | `DividerType` | `DividerType.FullWidth` | The type of divider to display. Defaults to `FullWidth`. |
| `ChildContent` | `RenderFragment?` | – | The content within this component. |
